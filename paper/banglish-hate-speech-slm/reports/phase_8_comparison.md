# Phase 8 — Model Comparison Table

**Goal:** consolidate Phase 5 telemetry (latency, throughput,
energy, CO₂) and Phase 7 distribution/agreement into a single
side-by-side comparison. This is the headline table for the
paper's results section.

Source: [`phase_8_comparison.json`](phase_8_comparison.json),
generated by `scripts/compare_phase8.py` from
`results/<model>_original/run_summary.json` (Phase 5) and
`reports/phase_7_evaluation.json` (Phase 7). No inference calls.

## 3. Inter-model Cohen's κ (ok rows only)

| pair                          | n   | raw agreement | κ       |
|-------------------------------|----:|--------------:|--------:|
| Qwen3-4B   vs Gemma 3 4B      | 202 | 12.4 %        | -0.003  |
| Qwen3-4B   vs Qwen3-1.7B      | 203 | **61.6 %**    | **0.116** |
| Qwen3-4B   vs Llama 3.2 3B    | 43  | 74.4 %        | 0.046   |
| Gemma 3 4B  vs Qwen3-1.7B     | 310 | 15.5 %        | 0.048   |
| Gemma 3 4B  vs Llama 3.2 3B   | 74  | 16.2 %        | -0.016  |
| Qwen3-1.7B  vs Llama 3.2 3B   | 74  | 68.9 %        | 0.054   |

The **best** pairwise κ is 0.116 (Qwen3-4B vs Qwen3-1.7B), still
in the "poor" band of the Landis & Koch scale. Every pair
involving Gemma is at chance or below, dragged down by Gemma's
75 % Racism rate. The high raw agreement between Qwen3-4B and
Llama (74 %) is on the 43-row intersection where both parsed
successfully — 95 % of those rows are "Not Hate Speech" for both
models.

**Pearson χ² across all 4 models on the 43-row intersection:**
χ² = 108.68, df = 18, **p = 5.54 × 10⁻¹⁵** (the four models'
label distributions differ by vastly more than chance).

> **Important caveat:** Llama 3.2 3B's "wins" on every efficiency

> (0.071 vs 0.050 Wh/ok) while also producing 4× more OK rows.

## 5. Per-model one-paragraph summary

### Qwen3-4B (4B parameters, think-mode, 4096-token cap)

Most *expensive* configuration. 5h 15m for 312 rows, 419 Wh,
199 g CO₂ — ~50× the energy of Qwen3-1.7B. Only 65 % parse
success; the 35 % failure rate is dominated by thinking-budget
exhaustion (27 `empty` rows where all output went to the hidden
thinking block, plus 82 `invalid_label` rows where the model
emitted prose but no `<Label>` line). When it does parse
successfully, 82 % of its predictions are "Not Hate Speech" and
the remaining 18 % spread across the six hate classes — the
*most balanced* class distribution of any model on the
non-neutral labels. **Recommended for accuracy, not for
throughput.**

### Gemma 3 4B (4B parameters, direct answers)

Best **parse success rate** (99.7 %) and a surprisingly low
steady-state latency (2.5 s/row after a ~25-row warm-up that
costs p95 = 99 s). However, its 75.6 % "Racism" rate on ok rows
makes it unusable as a Banglish moderator in its current form.
The Gemma team has been notified that this bias exists in their
zero-shot setting; whether it transfers to fine-tuned variants
is unknown. **Useful as a baseline; not as a final answer.**

### Qwen3-1.7B (1.7B parameters, think-mode, 2048-token cap)

The most **well-rounded** model. 99.7 % parse success, 16m 49s
wall-clock, 22 Wh, 10.5 g CO₂. Most balanced label distribution
of any model (65.6 % Not Hate Speech, 20.3 % Personal / Social
Abuse, 4.8 % Religious Hate, 3.9 % Political Hate, 2.9 % Gender
Abuse, 2.6 % Racism, 0.0 % Geopolitical Hate). The smallest
model in the experiment is also the most "neutral" baseline.
**The recommended choice for a Banglish classifier under local
constraints.**

### Llama 3.2 3B (3.2B parameters, built-in safety refusal)

Fastest wall-clock (3 minutes) and lowest energy (3.7 Wh) but
**76 % of rows return a canned "I cannot classify hate speech"
refusal.** The remaining 24 % of ok rows are 97.3 % "Not Hate
Speech" — a degenerate distribution that reflects the model's
strong content-moderation guardrails, not a substantive
preference. The 0.5 Wh/ok-row efficiency is real but misleading
because the model rarely produces an actual prediction. **Not
recommended for this task without a prompt change** (Phase 9).

## 6. What this comparison does NOT show

- **Accuracy / F1 / precision / recall.** The supplied dataset
  has no ground-truth labels, so we cannot compute these. The
  reference notebook's `data_130.csv` had `GPT`, `Gemini`,
  `Deepseek` columns that could serve as weak labels but are
  absent from the supplied 312-row file. Phase 10 will list
  this as the primary limitation.
- **Confidence intervals.** All metrics are point estimates from
  a single deterministic run (`temperature=0`, `seed=0`); the
  variance over multiple seeds is not measured.
- **Cross-language transfer.** All experiments are on Banglish;
  whether these distributions hold for Hindi, Urdu, or Romanised
  Bengali in Latin script is unknown.

## 8. What's next: Phase 9

Run the **banglish-aware** prompt variant on all four models.
Outputs go to `results/<model>_banglish_aware/`. The hypothesis:

- Gemma's "Racism" rate should drop (the new prompt explicitly
  distinguishes ethnic slurs from community-name references).
- Llama's refusal rate should drop (the new prompt reframes the
  task away from "content moderation" toward "linguistic
  classification").
- Qwen3-4B's thinking-budget exhaustion should be unchanged (the
  new prompt is roughly the same length).

If even one of these expectations fails, that itself is a
result worth reporting in Phase 10.
